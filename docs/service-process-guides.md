# Guias ilustrados dos serviços

## Plano executado

1. Identificar as cinco famílias e remover as medalhas das páginas locais.
2. Criar um percurso específico de cinco etapas e uma série de imagens ilustrativas para cada serviço.
3. Partilhar apresentação e dados entre páginas nacionais, cidades e freguesias.
4. Validar navegação, teclado, imagem e texto em computador e telemóvel.

## Imagens

Geradas com a ferramenta integrada imagegen, convertidas para WebP para uso no website. Não são fotografias de intervenções reais. Cada série contém cinco etapas e um detalhe de tecido; a interface identifica-as como imagens ilustrativas.
